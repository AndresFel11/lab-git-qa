Clasificación escenarios según pruebas:

1. Pruebas Unitarias:
- Calcular la retención en la fuente de un retiro según 8 rango de montos
- Verificar que la función que valida el formato de una cédula rechaza caracteres no numéricos.
- Validar que el conversor de fechas maneja bien los años bisiestos.
- Validar que la función de redondeo a dos decimales no pierde centavos en montos altos.
- Validar que el repositorio de portafolios devuelve lista vacía y no null cuando no hay registros



2. Pruebas de Integración:
- Confirmar que el servicio de aportes guarda correctamente en la base de datos.
- Comprobar que al crear un aporte se dispara la notificación al servicio de correo.
- Revisar que el cliente puede consultar su saldo desde la app móvil y que el valor coincide con el del extracto
- Confirmar que el endpoint de rentabilidad responde 401 cuando el token expiró.
- Comprobar que el consumo del servicio externo de validación de identidad maneja un timeout sin caer.
- Confirmar que el mensaje de error se muestra en pantalla cuando la API responde 500.

3. Pruebas E2E:
- Validar que un usuario nuevo puede registrarse, verificar su correo e iniciar sesión.
- Verificar que el flujo de retiro descuenta el saldo, genera el comprobante y envía el correo al usuario.
- Revisar que después de un despliegue el usuario todavía puede completar el proceso de vinculación.
- Verificar que la migración de datos dejó los saldos consistentes entre dos tablas
